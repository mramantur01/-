Как установить
  1. Нажмите «Скачать». Если Chrome спросит — нажмите «Всё равно скачать».
  2. Откройте скачанный файл KG-Taxi.apk (в уведомлении или в «Файлы» → «Загрузки»).
  3. Если появится «Установка запрещена» — нажмите «Настройки» и включите «Разрешить из этого источника», вернитесь назад.
  4. Нажмите «Установить». Готово — войдите через Google.
Не устанавливается?
«Приложение не установлено» / «Пакет конфликтует»

На телефоне уже есть старая версия KG Taxi из другого источника. Удалите её: Настройки → Приложения → KG Taxi → Удалить, и установите снова.

Окно «Play Защита» / «Рекомендуется проверить приложение»

Это обычное окно для приложений не из Google Play. Нажмите «Проверить приложение» (Scan app) — Google проверит KG Taxi и установит его. Или «Подробнее» → «Установить без проверки». Не нажимайте «Не устанавливать».

«Установка из неизвестных источников запрещена»

Нажмите «Настройки» в этом окне и включите «Разрешить из этого источника» для Chrome или «Файлов».

Xiaomi / Redmi / POCO

Если просит «проверить приложение» — нажмите «Установить всё равно». В Настройки → Конфиденциальность → Особые разрешения → «Неизвестные источники» разрешите Chrome.

«Ошибка синтаксического анализа пакета»

Файл скачался не полностью. Удалите его из «Загрузок» и скачайте ещё раз по Wi-Fi.
